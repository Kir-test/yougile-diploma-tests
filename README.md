Автоматизированное тестирование YouGile API и UI
О проекте

Дипломный проект по автоматизации тестирования системы управления проектами YouGile.

Проект предназначен для автоматизированной проверки функциональности API и пользовательского интерфейса приложения.

Технологии
Python
pytest
Requests
Selenium
Allure
Структура проекта
api_tests/ — API-автотесты.
ui_tests/ — UI-автотесты.
ui_tests/pages/ — классы страниц по паттерну Page Object.
config/ — конфигурация тестов.
requirements.txt — зависимости проекта.
Установка

Инструкция по установке зависимостей и запуску тестов будет дополнена после настройки проекта.

Отчёты

Для формирования и просмотра отчётов будет использоваться Allure.
